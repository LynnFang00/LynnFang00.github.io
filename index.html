Continuous sensor context for a frozen LLM

Can a complete inertial-sensor window become one continuous context vector inside a frozen language model—without converting values into text?

My approach

What I've learned from building.

These are habits I'm developing through coursework, research, and personal projects.
01

Define the goal

Decide what the project needs to do and how I will measure success.

02

Start with a baseline

Try a simple approach first so I can tell whether a more complex method helps.

03

Test the result

Use held-out data and control tests, then explain the limitations honestly.

04

Build the whole project

Connect the model to the data, backend, interface, tests, and deployment.
