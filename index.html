02 / Multimodal ML

Continuous sensor context for a frozen LLM

Can a complete inertial-sensor window become one continuous context vector inside a frozen language model—without converting values into text?

Direct0.8921macro-F1
Context0.8990macro-F1
Shuffled0.1688macro-F1

The 0.7302 shuffled-control drop showed that the model used the matching sensor embedding. The honest conclusion: the interface works, but the direct classifier remains the better HAR product.
